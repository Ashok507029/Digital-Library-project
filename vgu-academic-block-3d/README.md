# 🏛️ VGU Campus Academic Block 3D Model (Standalone Project)

A photorealistic, fully interactive 3D architectural model of the Vivekananda Global University (VGU) Academic Block built using **Three.js** and WebGL.

## 📁 Project Structure
- `index.html` — Core 3D scene file containing Three.js rendering, lighting, materials, building wings, gallery connectors, and interactive UI controls.
- `server.js` — Standalone Node.js Express server.
- `package.json` — Dependencies and run scripts.

## 🚀 How to Run

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Local Server
```bash
npm start
```
The server will start at: `http://localhost:3001/`

## 🎨 Architectural Features
- **Real Side Wings:** 4-column window sub-blocks, white vertical fin feature towers, and 7-story balcony walkway corridors with railings.
- **Center Academic Block:** Ground floor open hall with support pillars & study lounge, side entry stairs, and 5 window floors.
- **Connecting Bridges:** Elevated 4-corridor level gallery bridges connecting side wings to center block.
- **Executive Portico Canopy:** Front canopy with coffered waffle ceiling grid, red marble column bases, and detailed parked cars.
- **Lighting Controls:** Toggle between Day Sunlight and Sunset Dusk Mode.
